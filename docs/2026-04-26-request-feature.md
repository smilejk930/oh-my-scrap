1. 데스크탑 뷰에서 목록/카드뷰 토글버튼 크기 수정(AI 토글, 영문/한글 토글 버튼과 크기를 동일하게 변경)
2. 모바일뷰 하단 오른쪽 메뉴에 `Input` 단어를 `Add`로 변경
3. UX 향상을 위해 add scrap 메뉴 삭제하고 Archive 메뉴로 통합
    - url을 스크랩하고 저장된 스크랩 목록을 보는 메뉴가 분리되어 있어서 번거로운 불편함이 존재함
    - 기존 상단에 `My Archive` 명칭을 `Oh My Scrap`으로 변경
    - add scrap 다이얼로그 추가
        - url 입력창에 url 붙여넣기 기능
        - 화면 전환 없이 url 스크랩 할 수 있게 기능 고도화
        - 복사한 url을 바로 붙여넣을 수 있게 Past 버튼 추가
        - 기존 상단에 있던 OFF/AI 토글 버튼, EN/KO 토글 버튼 삭제하고 add scrap 다이얼로그에 배치
        - 모바일에서는 url 입력 창이 하단에 위치(사용자 편의성)
        - 데스크탑에서는 url이 중앙에 위치
    - 모바일 하단 메뉴 수정
        - 왼쪽: 목록뷰/카드뷰 버튼
        - 오른쪽: Add 버튼
    - 데스크탑 화면에서 왼쪽 사이드바 제거(로그아웃 버튼을 모바일과 비슷하게 위치 이동)
4. 모바일 웹 브라우저에서 url 입력창 붙여넣기 컨텍스트 메뉴 사라짐 증상 수정
    - 복사한 url을 붙여넣기 위해 url 입력창을 손가락으로 꾹 눌러 `붙여넣기` 컨텍스트 메뉴를 보이게 해야 하는데 새로고침 되듯이 잠깐 보였다가 사라짐(안드로이드, ios 둘다 동일 증상 발생)
