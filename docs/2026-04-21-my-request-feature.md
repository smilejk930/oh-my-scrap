내가 휴대폰 또는 웹에서 유용한 컨텐츠를 읽던 중 유용하다고 생각할때 따로 url을 저장하곤해.
그런데 이렇게 저장만하고 안볼때가 많아. 그래서 스크랩 웹앱을 만들고 싶어.
프로젝트명은 `oh-my-scrap`이야.
내가 생각한 기능에 대해 요구사항을 정리해볼께.

## 목적
- 웹서핑 중 유용하다고 생각되는 url을 스크랩하여 정리

## 기능 요구사항
- url을 gemini(AI)가 분석하여 스크랩하는 웹앱
- 모바일웹앱 구현(PC 웹, 모바일에서는 크롬 등 브라우저를 이용해서 사용)
- 구글계정으로 로그인할 수 있게 api를 사용
- 웹 url을 복사해서 입력하면 해당 url정보를 기반으로 row 1줄 생성
- row는 gemini가 해당 url을 요약하여 대표적인 문구로 생성, 모바일에서도 보여야 되니 대략 20글자(20글자는 추후 변경될 수도 있음) 이내로 구성
- 추후 해당 URL의 요약내용을 저장할 수도 있으니 데이터베이스에 해당 컬럼을 미리 구성
- url에 썸네일이 존재한다면 왼쪽에 썸네일 보여주고 이후 문구 보여줌
- 해당 row가 더 추가되어 결국 게시판 목록 형태로 구성
- 카드뉴스형식으로 보여줄지 목록으로 보여줄지 사용자가 토글할 수 있게 최상단에 버튼 위치
- row 생성시 gemini가 분석해서 카테고리(태그)를 생성하거 사용자가 선택 또는 검색해서 컨텐츠를 찾을수 있게 구현
- 생성된 row 클릭 시 새탭을 열어서 이동하거나 화면을 수직으로 2분할하여 오른쪽에 보여주기(구현 가능한 방향으로 개발)
- ORDER BY는 ROW가 생성된 일자 DESC
- 검색 조건은 오늘, 일주일, 한달, 한달 이후, ROW 내용
- 컨텐츠는 사용자별로 저장되고 타 사용자에게는 보이지 않음
- 스크랩 관련 메뉴는 2개임
    1. 스크랩 URL 입력하는 메뉴: URL을 입력하면 분석된 대표 문구(20글자 이내)를 보여줌.
    2, 스크랩 된 정보를 보여주는 메뉴

## 데이터 획득 경로
- URL을 웹을 통해서 입력
- 텔레그램 API를 이용해서 텔레그램앱을 통해 URL 입력

## 디자인 방향

- 모바일, pc웹 호환 가능해야 함
- 디자인은 심플하게. 톤매너는 깔끔하게.
