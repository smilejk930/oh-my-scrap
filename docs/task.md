# oh-my-scrap 요구사항 상세 태스크 리스트

## 목적
- [x] 웹서핑 중 유용하다고 생각되는 url을 스크랩하여 정리

## 기능 요구사항
- [x] url을 gemini(AI)가 분석하여 스크랩하는 웹앱
- [x] 모바일웹앱 구현(PC 웹, 모바일에서는 크롬 등 브라우저를 이용해서 사용)
- [x] 구글계정으로 로그인할 수 있게 api를 사용
- [x] 웹 url을 복사해서 입력하면 해당 url정보를 기반으로 row 1줄 생성
- [x] row는 gemini가 해당 url을 요약하여 대표적인 문구로 생성, 모바일에서도 보여야 되니 대략 20글자 이내로 구성
- [x] 추후 해당 URL의 요약내용을 저장할 수도 있으니 데이터베이스에 해당 컬럼을 미리 구성
- [x] url에 썸네일이 존재한다면 왼쪽에 썸네일 보여주고 이후 문구 보여줌
- [x] 해당 row가 더 추가되어 결국 게시판 목록 형태로 구성
- [x] 카드뉴스형식으로 보여줄지 목록으로 보여줄지 사용자가 토글할 수 있게 최상단에 버튼 위치
- [x] row 생성시 gemini가 분석해서 카테고리(태그)를 생성하거 사용자가 선택 또는 검색해서 컨텐츠를 찾을수 있게 구현
- [x] 생성된 row 클릭 시 새탭을 열어서 이동하거나 화면을 수직으로 2분할하여 오른쪽에 보여주기(구현 가능한 방향으로 개발)
- [x] ORDER BY는 ROW가 생성된 일자 DESC
- [x] 검색 조건은 오늘, 일주일, 한달, 한달 이후, ROW 내용
- [x] 컨텐츠는 사용자별로 저장되고 타 사용자에게는 보이지 않음
- [x] 스크랩 관련 메뉴는 2개임 (1. 입력 2. 보관함)
